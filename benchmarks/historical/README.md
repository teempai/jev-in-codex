# Historical development evidence

These exported measurements retain the positive prototype round, all negative scored phases, the permission failure and the optional-use pilot. See index.json for session counts. Each phase contains its synthetic inputs, reference labels, outputs, timings, usage, provider observations and relevant Codex events. The default product exposes only the admitted feedback policy; historical policies are data, not registered capabilities.

This is a publication export, not the untouched local archive. Host-specific paths were replaced with placeholders and thread-start identifiers were omitted; numeric measurements and labels are unchanged. Authentication files, raw stderr/telemetry, private launch configuration and keys are excluded. The original local archive remains intact. Original source-freeze hashes do not apply to redacted files.

These phases used earlier experimental engines and harnesses, not the current production port. Do not rerun the current server and label it an exact historical reproduction. The current release has its own runnable paired benchmark and result record one directory above. Historical report links and implementation references describe the original local study; the retained evidence is organized under each phase here.

The gate in feedback-64 failed: 21.8% less input but 10.6% slower. The subsequent feedback-parallel round passed: 28.0% less input and 21.4% less time. Its post-hoc whole-pair error sensitivity was 21.8% less input and 15.5% less time. These are exploratory results on 64 unique synthetic records, with technical repeats. No independence, statistical significance or general savings claim is implied.
